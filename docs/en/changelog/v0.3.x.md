# SoDialog v0.3.17

Release date: 2026-08-10

## Added

- Added the `openImagePreview` and `bindImagePreview` image preview APIs.

## Changed

- The default immersive preset is centered and hides the header, toolbar, and scrollbars.
- The panel follows the scaled image while remaining inside the padded viewport.
- The default zoom range is 25%–400%, with configurable controls, overflow, initial scale, and sizing behavior.

## Upgrade Notes

Existing Dialog APIs remain compatible; image preview is additive.
