# SoDialog v0.3.17

發布日期：2026-08-10

## Added

- 新增 `openImagePreview` 與 `bindImagePreview` 圖片預覽 API。

## Changed

- 預設採用置中且隱藏標題列、工具列與捲軸的沉浸模式。
- 面板跟隨縮放圖片等比例調整，並限制在視口留白後的可用範圍內。
- 預設縮放範圍為 25%–400%，可設定控制列、溢出、初始比例與尺寸策略。

## Upgrade Notes

既有 Dialog API 保持相容；圖片預覽為新增功能。
