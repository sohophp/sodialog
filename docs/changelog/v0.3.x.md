# SoDialog v0.3.17

发布日期：2026-08-10

## Added

- 新增 `openImagePreview` 与 `bindImagePreview` 图片预览 API。

## Changed

- 默认使用无标题栏、无工具栏、无滚动条的居中沉浸预设。
- 面板跟随缩放图片同比扩缩，并限制在视口留白后的可用范围内。
- 默认缩放范围为 25%–400%，支持工具栏、溢出、初始比例和尺寸策略配置。

## Upgrade Notes

Core Dialog API 保持兼容；图片预览为新增能力。
